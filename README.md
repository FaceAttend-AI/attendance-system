\# 🎓 Automated Attendance System Using Face Recognition \& Deep Learning



\## 📌 Project Overview

AI-powered attendance system using Deep Learning and Face Recognition.

Built with DeepFace (FaceNet model), OpenCV, TensorFlow, and Streamlit.



\## ✨ Features

\- ✅ Real-time face detection and recognition

\- ✅ Automatic attendance marking in database

\- ✅ Anti-spoofing liveness detection (blink test)

\- ✅ Multi-camera support

\- ✅ Email daily attendance reports

\- ✅ Mobile-friendly web interface

\- ✅ Streamlit web dashboard with CSV export



\## 🛠️ Tech Stack

| Component | Technology |

|---|---|

| Language | Python 3.10 |

| Face Detection | OpenCV Haar Cascade |

| Face Recognition | DeepFace + FaceNet |

| Deep Learning | TensorFlow 2.21 |

| Database | SQLite |

| Dashboard | Streamlit |

| Mobile App | Flask |

| Anti-Spoofing | OpenCV Eye Detection |
